# سيناريو المشروع: نظام إدارة المتجر الإلكتروني (E-Commerce Store)

ترغب منصة تجارة إلكترونية في بناء نظام خلفي (Web API) لإدارة كتالوج المنتجات وفق المتطلبات التالية:

### 1. الأقسام والمنتجات
* يتضمن المتجر مجموعة من **الأقسام** (مثل: إلكترونيات، كتب، برمجيات).
* كل **منتج** يحتوي على: اسم، رمز تعريفي فريد (SKU)، سعر، وتاريخ إضافة، ويتبع لقسم محدد.
* لا يُسمح بحذف أي قسم طالما يحتوي على منتجات معروضة داخله.

### 2. طبيعة المنتجات
تنقسم المنتجات إلى نوعين رئيسيين:
* **منتجات مادية (Physical):** تتطلب تسجيل وزن الشحنة، أبعادها، وموقع تخزينها في المستودع.
* **منتجات رقمية (Digital):** تتطلب تسجيل رابط التحميل، حجم الملف بالميغابايت، وصيغة الملف (مثل: PDF أو ZIP).

### 3. مراجعات العملاء
* يتيح المتجر للعملاء كتابة **تقييمات ومراجعات** تشمل: اسم العميل، التقييم (من 1 إلى 5)، والتعليق.
* في حال حذف أي منتج، تُحذف معه كافة المراجعات الخاصة به تلقائياً.

### 4. الوسوم الترويجية
* يدعم المتجر **وسوماً** لتمييز المنتجات (مثل: الأكثر مبيعاً، عرض خاص، جديد).
* يمكن للمنتج أن يحمل وسوماً متعددة، والوسم الواحد يمكن استخدامه مع منتجات مختلفة، مع تسجيل تاريخ إسناد كل وسم ومنع تكراره لنفس المنتج.

---

### المطلوب برمجياً:
بناء واجهة برمجية (RESTful API) تتيح:
1. إضافة منتج جديد بكامل تفاصيله (حسب نوعه وقسمه ووسومه).
2. تعديل بيانات المنتج أو تحديث سعره بشكل منفصل.
3. استعراض المنتجات بكافة بياناتها، أو حذف منتج معين.
4. إضافة مراجعة لمنتج، وإسناد وسوم جديدة له.
5. إدارة الأقسام والوسوم (إضافة، استعراض، وحذف).
